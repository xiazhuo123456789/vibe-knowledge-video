# 原片逐秒分析数据（风格逆向一手资料）

对 8 条「Vibe知识大赏」原片（共约 17.5 分钟）的逐秒 OCR 记录。

## 方法

1. 通过浏览器获取原片 1080p 源并下载（仅本地分析用，不入库）
2. `ffmpeg` 每秒抽帧（共 1091 帧）
3. `tesseract`（chi_sim+eng）逐帧 OCR，保留画面上所有可识别文字
4. 辅以：音频转录（证明无旁白）、BPM 自相关测量（76-78）、
   逐帧亮度差分（运动密度均值 3.97）、行级亮度带检测（字幕带 85-91%）
