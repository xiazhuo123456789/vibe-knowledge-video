# 叙事弧模板（8 条原片逐段拆解）

## 通用六段式（占比按时长 130s 计）

| 段 | 时长占比 | 功能 | 原片例证 |
|---|---|---|---|
| 1 冷开场钩子 | 0–8s (6%) | 反直觉问题/悬念，字幕极短 | "同样的8个人，同样的心意 / 只改一件事：谁先开口" |
| 2 历史锚点 | 8–30s (17%) | 年份+地点+人物+文献再现 | 1962 论文书影 + Gale/Shapley 人物卡 |
| 3 机制模拟 | 30–90s (46%) | 核心动画推演，分步骤标注 | 男生先开口→暂时留下→被换掉；4×4 排名表 |
| 4 反直觉转折 | 90–105s (12%) | "还有一个反直觉的细节" | 开口的一方名次只掉不升，却拿到最优稳定结局 |
| 5 现实落点 | 105–120s (12%) | 诺奖/现实系统/生活映射 | 2012 诺奖→医学生分配→"没有两个人想一起离开" |
| 6 声明+引用收尾 | 120–130s (8%) | 免责声明+出品+学术引用+互动问题 | 声明卡→参考论文→"你选择如何活着，本身就是答案" |

---

## 逐片拆解

### 视频1《月老的算法》(143s) — Gale-Shapley 稳定匹配
- 钩子：同样 8 人同样心意，只改谁先开口
- 锚点：唐代月老传说→1962 论文《College Admissions and the Stability of Marriage》
- 模拟：4男4女排名表→第一次（男生开口）逐步配对动画，注释"暂时留下""西更喜欢南——东被换掉了"→第二次（女生开口）→并排对比两次结局
- 转折：每个男生左边更好/每个女生右边更好/都稳定无「私奔」对；开口方名次只降不升却拿最优
- 落点：2012 诺奖（沙普利/罗斯）→医学生分医院、学生分学校
- 收尾：声明（数学模型非恋爱建议）+ 论文引用
- 独有装置：排名卡片矩阵、左右分屏对比、"数学模型演示，非恋爱建议"常驻角标

### 视频2《多修一条路，为什么反而更堵》(146s) — 布雷斯悖论
- 钩子：多修一条路，所有人反而更慢
- 锚点：1990 纽约地球日封 42 街→车流反而更顺（纽约时报报道再现）；1968 布雷斯论文《Unternehmensforschung》书影
- 模拟：家→公司路网图，新路未修/已通车两状态；第1天走新路快→均衡后 40 分钟
- 转折：人人都选最快的路→人人都抢的捷径就是最慢的路（纳什均衡）
- 落点：今天导航"抄小路快"所有人都收到
- 独有装置：年代地点戳（1990·纽约·地球日）、报纸再现、路网演化对比

### 视频3《运气的形状》(130s) — 概率论诞生史
- 钩子：骰子落下之前，谁也不知道答案 / 运气能被计算吗
- 锚点链（编年体）：1494 帕乔利《算术大全》分赌注问题→1564 卡尔达诺《论赌博游戏》→1620 伽利略掷骰计数→1654 巴黎 德·梅雷骑士→帕斯卡×费马通信（法文原信）
- 模拟：先到 60 分赌局；三骰和的分布计数表；帕斯卡-费马通信解法
- 转折：一个人的生死无法预料，一整座城的数字却稳定得惊人（1662 格朗特死亡表）
- 落点：1713 雅各布·伯努利《猜度术》大数定律；想要"几乎确定"需要摸 25,550 次
- 独有装置：编年体多点锚点、法文原信、数学家通信场景

### 视频4《倒霉的事总扎堆》(130s) — 泊松聚集/聚类错觉
- 钚子：倒霉的事总扎堆，是被针对了吗？《它在瞄准谁》
- 锚点：1944 伦敦 V-1 飞弹 2419 枚，传言专挑某些街区、没炸的住着间谍
- 模拟：1946 精算师克拉克把伦敦南部切 576 格数弹坑→电脑随机撒一遍→两边几乎一样
- 转折：随机的长什么样（真实伦敦 vs 均匀撒点对比图）
- 落点：排位连跪 5 把、同班同天生日、双色球连号、抽签抽到自己——同一回事
- 独有装置：真实地图 vs 随机地图对比、生活案例四连

### 视频5《第几个人》(131s) — 秘书问题/37%法则（**逐秒级完整拆解**）

- 1-4s 钩子：假如这一生，你会遇见10个可能的人
- 7-8s：他们一个一个出现，错过了，就不能回头（**晾衣绳挂卡片**：红绳+木夹+米白纸卡，正面"6"其余"?"，持续摆动）
- 13-16s：你该在第几个人，停下来？/ When should you stop looking?
- 17-20s **标题卡**：VIBE知识大赏 / 《第几个人》金色衬线 / 什么时候，该停止相亲？/ When to Stop Looking
- 21-28s **规则卡**：游戏规则 / The rules of the game — ①顺序随机，一个一个见 ②当场决定，拒绝了不能回头 ③你只想要最好的那一个（金色线框图标+英文逐条对照）
- 29-36s 两难：太早：更好的，还在后面 / 太晚：最好的，早已错过
- 37-40s **文献复原**：JANUARY 1950 · WASHINGTON / The Fiancée Problem / Merrill M. Flood + 红印章「未婚妻问题」；数学家弗勒德提出了它
- 41-44s：1960《科学美国人》刊出，数学家们争相求解（期刊封面）
- 45-48s：而三百多年前，早有人用人生，把这道题做了一遍 / Centuries earlier, someone had already lived it.
- 49-52s：1611 布拉格 PRAGUE / 天文学家开普勒，失去了妻子（人物剪影+铭牌+地点戳）
- 53-56s：之后两年，他先后考虑了11位再婚对象
- 57-59s：犹豫、错过、再回头，他选了第5位 / 第5位 苏珊娜 / 1613年成婚，婚后幸福 / 1613 · 埃尔丁
- 61-62s：后来算出的最优解，也恰好指向第5位
- 63-64s：如果人生可以重来一万次？/ What if you could live it ten thousand times?
- 65-71s **万人模拟网格**：迷你卡片点阵滚动点亮打勾，计数器"选中了最好的那位"，参数标签滚动——先看5位 37.4% → 先看7位 26.8% → 先看9位 10.0%；规则注释：先只看不选前k位，再选第一个更好的 / Skip the first k. Then take the first one better than all of them.
- 72-78s **成功率曲线**：手绘曲线生长，x轴"只看不选的比例 0-100%"，金点+虚线标注峰值 1/e ≈ 36.8%
- 83-84s：先看37%，再出手 / Look at the first 37%. Then leap.
- 86-92s 双段卡：探索期，只看不选 | 决定期，遇到更好的，就选；前37%：只看不选，建立你的标准；之后：遇到第一个比前面都好的，就是Ta / After that: the first one better than everyone before. That's them.
- 94-97s 泛化数字滚动：人数10→39.9% / 人数100→37.1% / 人数1000→36.8%；人数再多，答案都稳稳停在37%附近
- 98-105s **年龄时间轴**：20-35岁刻度尺，37%分位点落金点"25.5岁 / 37% of the way there is 25.5."；行动建议：多认识，多了解 / 遇到比之前都好的，认真考虑
- 106-109s 泛化四连：看房 招聘 找车位 选offer / Renting Hiring Parking Job offers
- 110-115s 参数变体：对方也可能拒绝你 / If they might say no → 一半可能拒绝→25%就出手；可以回头，像开普勒 / If you can go back, like Kepler → 61%
- 116-121s 温柔转折：但最好的策略，成功率也只有37% / But even the best strategy works only 37% of the time.；63%的时候，最好的人依然会错过
- 122-125s：所以错过了，不是你不够好 / So if you missed them, it wasn't because you weren't enough.；是那些相遇，教会了你什么是好
- 126-129s 收尾：爱情没有最优解 / Love has no optimal solution.；但每一次认真的相遇，都算数

### 视频6《你的耳朵在下注》(125s) — 预测编码/多巴胺
- 钩子：这首歌马上要"炸"了→你的大脑已经押好了注→……没炸？再来一次
- 锚点：2011 年科学家扫描听歌人的大脑
- 模拟：期待值曲线 vs 实际 drop；倒计时字幕"注意：这首歌真的要 drop 了"→"从这一秒起你的大脑在分泌多巴胺"（15.1→11.1→…）
- 转折：高潮前十几秒多巴胺就开始；"等"本身就是快乐；片中真实加了一小节让观者体验延迟满足（元叙事！）
- 落点：2025 年 400 人实验——有人偏爱好猜有人偏爱意外，与学没学过音乐无关；副歌重复=让你押中
- 独有装置：观者即被试的元叙事、期待值曲线、倒计时

### 视频7《虚无主义？然后呢》(166s) — 尼采精神三变
- 钩子三连：为什么赚钱？→这一切都没有意义→一切都没意义，然后呢？
- 锚点：1882 尼采"上帝已死"（《快乐的科学》）；哥白尼 1543 宇宙祛魅铺垫
- 模拟：消极虚无（虚空场景）→瓦解是为了重塑→精神三变：骆驼（你应该…）→狮子（屠龙）→孩子（创造）
- 转折：狮子只会摧毁无法建立；孩子不求永恒，全身心投入创造本身
- 落点：没有上帝也没有现成地平线→你为自己选的最不起眼的活法，就是你亲手画下的地平线
- 收尾："你选择如何活着，本身就是答案"→"你现在是骆驼、狮子，还是孩子？"
- 独有装置：主题词常驻（虚无主义）、三段变身动画、龙、开放互动结尾

### 视频8《悲观主义与叔本华》(119s) — 钟摆理论
- 钩子：为什么我们总是幻想喧嚣背后的空荡？
- 锚点：叔本华"人生就像一只钟摆，在痛苦和无聊之间来回摆荡"
- 模拟：欲望（想要）→满足后的无聊；假期第三天发呆、追很久的人索然无味、聚会迁就别人（聊天气泡"哈哈哈""真的假的"）
- 转折：听起来很悲观？→看一幅画忘了时间→独处（Einsamkeit 德文）→"谁不热爱独处，谁就不热爱自由"
- 落点：散场后的那阵空，不再是失落，而是自由
- 独有装置：钟摆意象贯穿、聊天界面模拟、德文关键词、情绪反转收尾

## 通用剧本模板（照填）

```
【钩子】(0-8s)
  2-3 句极短字幕，抛出反直觉问题或让观者代入的场景。
  句式：A，却 B？/ 如果 X，你会 Y 吗？/ 同样的__，只改一件事：__

【历史锚点】(8-30s)
  顶标签：年份 · 地点 · 事件
  画面：文献/论文/报纸再现（真实标题）+ 人物铭牌（姓名+年代）
  旁白：把"姻缘"写成了一道题 / 这道题一悬就是 160 年

【机制模拟】(30-90s)
  分 3-5 个步骤，每步一个动作+一句注释+一句旁白。
  规则先立（规则卡），再逐步推演，状态标签常驻。
  关键词用「」高亮，数据用大号数字。

【反直觉转折】(90-105s)
  旁白固定句式："还有一个反直觉的细节：" / "但最_的，恰恰是_"
  画面：前述结论并排对比/翻转/放大。

【现实落点】(105-120s)
  从历史拉回今天：诺奖、现实系统、观者自己的生活。
  旁白给一句可转发的金句（≤16 字）。

【收尾卡】(120-130s)
  声明卡（模型演示/非建议）→ @出品 + 学术引用 → 互动问题
```

## 选题公式

- **硬知识 + 私人相关**：相亲、堵车、倒霉、听歌、独处——大理论必须落在"你"身上。
- **一个具体年份开路**：1494/1611/1944/1962/1882——历史感=可信度=大片感。
- **一个反直觉结论做记忆锚**：谁先开口谁如愿 / 37% / 随机和真实地图一样 / 等待即快乐。
- **金句收尾可转发**："你选择如何活着，本身就是答案""散场后的空，是自由"。
