# Vibe知识大赏 风格 DNA 完整规范

> 逆向工程自 8 条原片：Iwanau《月老的算法》《多修一条路》《运气的形状》、Juno《倒霉的事总扎堆》《第几个人》《你的耳朵在下注》、叁号暗房《虚无主义》《悲观主义与叔本华》。全部由 Claude Opus 5.5 代码生成。

## 2. 画面五区布局（y 坐标按 1080 高）

```
┌─────────────────────────────────────────────┐
│ y=40-80   左上: @作者水印    顶中: 场景/时代标签  │  ← 全片恒定，系列感来源
│                                             │
│                                             │
│ y=280-700 中央: 主视觉动画区                    │  ← 卡片/曲线/格子/文献/人物
│            (占画面 30%-65%)                   │
│                                             │
│ y≈750 (70%) 画面注释带                         │  ← 解释当前动画的小字
│                                             │
│ y≈920-980 (85-91%) 双语旁白字幕带               │  ← 中文主句 + 下方英文斜体小字
└─────────────────────────────────────────────┘
```

- **水印**：`@Iwanau` / `@Juno` / `叁号暗房`——小号、半透明、左上角，全片不动。
- **顶部标签**：随章节切换的"状态条"，如 `悲观主义`（哲学片常驻主题词）、`1990 · 纽约 · 地球日`（年代地点戳）、`第一次：男生先开口`（模拟状态）、`游戏规则`（规则卡）。
- **画面注释**：对中央动画的即时解说，如"注意：只是「暂时留下」""西更喜欢南——东被换掉了""纽约时报 1990 年 12 月 25 日报道直译，图为示意"。
- **双语旁白字幕**：中文主句（46px 粗体白字）**下方永远带一行英文斜体小字**（26px，EB Garamond italic，#8A8AA0）——实测每句都有，如"你该在第几个人，停下来？ / When should you stop looking?""先看37%，再出手 / Look at the first 37%. Then leap."。这是 Juno 系列的标志性版式，写剧本时必须同时写好中英文两行。
- 每句 ≤ 20 字；关键词用「」框出（如「稳定」「互为第一」「私奔」）。

## 2.6 视觉母题库（实测自原片，优先复用）

1. **晾衣绳卡片**（视频5）：红绳横贯画面，纸质卡片用木夹挂成一排，未翻开的卡背面是"?"，翻开的露出数字（如"6"）——表达"一个一个出现，错过了不能回头"的不可逆顺序。卡片做旧米白纸质感+打孔。
2. **规则卡**（视频5）：`游戏规则 / The rules of the game` 标题 + 金色线框图标（书页/门/皇冠）+ 编号①②③，每条中文规则下附英文斜体。
3. **文献复原件**（全系列）：顶部一行小字 `JANUARY 1950 · WASHINGTON`（月份+年份+地点），衬线斜体标题《The Fiancée Problem》，作者名，右下角盖**红色中文印章**「未婚妻问题」；纸张做旧、微斜角度、投影。
4. **万人模拟网格**（视频5 65-71s）：数十行迷你卡片组成的点阵，随模拟滚动点亮/打勾（@），角落滚动计数器"选中了最好的那位"，右侧参数标签"先看5位 成功率37.4%"。
5. **成功率曲线**（视频5 72-78s）：手绘感曲线在暗底上生长，x 轴"只看不选的比例 0%-100%"，峰值点用金点+虚线垂线标注 `1/e ≈ 36.8%`。
6. **时间轴映射**（视频5 98-105s）：20-35 岁年龄刻度尺，37% 分位点落金点标注 `25.5岁`，下方两行行动建议"多认识，多了解 / 遇到比之前都好的，认真考虑"。
7. **泛化标签列**（视频5 106-109s）：四个词依次入场"看房 招聘 找车位 选offer / Renting Hiring Parking Job offers"。
8. **参数变体对比**（视频5 110-115s）：左侧条件卡"对方也可能拒绝你 / 可以回头，像开普勒"，右侧数值变化"25%就出手 / 61%"。
9. **卡片系统**（视频1）：人物卡片矩阵排列、配对连线、交换换位。
10. **地图/路网**（视频2/4）：简化路网、伦敦格子、真实vs随机对比。
11. **人物剪影+铭牌**：开普勒、帕斯卡、尼采——剪影 + 姓名年代牌 + 地点戳（布拉格 PRAGUE / 埃尔丁）。

## 3. 配色与字体

- 背景：深蓝黑 `#050510` 到 `#12122a`，可用极淡的星点/噪点纹理。
- 前景：白 `#EAEAF2` 为主文字色。
- **两位作者的强调色不同**：
  - Iwanau（理科模拟风）：暖橙 `#E8A87C`
  - **Juno（卡片纸艺风）：金 + 米白纸张**——金色衬线标题 `#C9A96A`、米白卡片 `#EDE4D3`、红色印章 `#B53A2F`、金色线框图标（标题卡、晾衣绳卡片、规则卡、文献复原件都是纸质感）
  - 叁号暗房（哲学风）：冷白 + 主题色
- 辅助灰 `#8A8AA0` 用于注释、英文小字。
- 字体：
  - 标题/字幕：中文粗黑体（Noto Sans SC 700/900）
  - **标题卡与文献标题：中文衬线体（Noto Serif SC 900）金色**
  - 西文引文：EB Garamond 斜体
  - 英文小字/大写标签：无衬线大写 + letter-spacing 拉宽（如 `VIBE知识大赏`）
  - 数据/年份：等宽或加大号粗体
- 数字（年份、概率、百分比）要**大而醒目**，是节奏锚点：`1494` `1962` `2012` `37%` `25,550` `1/e ≈ 36.8%` `25.5岁`。

## 4. 视觉元素库（按出场频率）

1. **卡片系统**：人物/选项/卡片用圆角矩形+emoji 或简单几何肖像，可排列、配对、飞移、交换——月老算法的 4男4女、秘书问题的 10 人序列。
2. **历史文献再现**：论文首页（真实标题排版）、古籍书影（算术大全/猜度术）、报纸头条（纽约时报），做旧质感+年代字体，配"图为示意"标注。
3. **地图/路网**：城市简化路网图、伦敦格子地图（576 格）、配色区分新旧路。
4. **图表**：成功率曲线（37% 最优解）、概率分布、钟摆示意，坐标轴+手绘感曲线。
5. **对话气泡**：模拟聊天/聚会（"哈哈哈""真的假的"）。
6. **人物剪影**：简单几何人物（开普勒、帕斯卡、尼采），配姓名+年代铭牌。
7. **概念意象**：钟摆（叔本华）、骆驼→狮子→孩子三段变体（尼采）、骰子/命运之轮（概率）、多巴胺/脑区示意。
8. **奖章/证书**：诺贝尔奖牌、期刊封面（科学美国人）。

## 5. 动效规范（含实测数据）

- **画面密度实测**（视频5 逐秒分析）：相邻帧亮度差异均值 3.97，模拟/演示段峰值 21–34，全片静止秒仅 29/130——**画面必须"一直在动"**，即使文字停留时也要有微动画（卡片浮动、星点闪烁、进度点推进）。
- **缓动**：全部用 ease-in-out / 弹簧，**禁止匀速滑动**。
- **进场**：卡片从侧边滑入+微缩放；纸质元素带轻微旋转落定；文字逐字或整句淡入上移 8px；图标描边自绘（stroke-dashoffset 动画）。
- **强调**：关键词出现时颜色从白变强调色+轻微放大 1.05×；数字用快速滚动计数（如成功率 39.9%→37.1%→36.8%）。
- **转场**：内容长出来的——卡片飞散重组、曲线延伸成地平线、格子放大成地图、卡片翻页。**禁止黑场淡入淡出**（原片硬切极少，仅 3-4 次/片）。
- **节奏**：与 BGM 拍点对齐（77BPM ≈ 0.78s/拍），关键动作落在小节头。
- **持续生命感**：背景星点缓慢闪烁、卡片微浮动、纸片轻微摆动，杜绝静止画面超 4 秒。
- **模拟类场面的呈现节奏**：先立规则卡（5-8 秒）→ 再逐步推演（每步 2-4 秒一个动作+注释）→ 再泛化对比（并排/并排参数变化）。

## 6. 严谨性装置（本风格的灵魂）

- **双语引文**：关键史料给原文——`"Je vois bien que la vérité est la même à Toulouse et à Paris."`（帕斯卡致费马信）配中文翻译。
- **示意标注**：凡再现历史图像必标"图为示意""报道直译"。
- **免责声明卡**：结尾前固定格式——`声明：本片是数学模型演示，不是恋爱建议。真实的人，心意会变；机会，也不止一轮。`
- **学术引用卡**：`参考：D. Gale & T. S. Shapley, "College Admissions and the Stability of Marriage", The American Mathematical Monthly (1962)`。
- **出品卡**：`@Iwanau 出品` + 互动问题（"你现在是骆驼、狮子，还是孩子？"）。
- **数据出处**：研究年份+样本量（"2011 年，科学家扫描听歌人的大脑""2025 年，400 多人听旋律"）。

## 7. BGM 规范（numpy 合成）

- 76–78 BPM，4/4 拍；小调（A minor / D minor）。
- 织体：低音 pad 长音 + 钢琴柱式和弦（每小节） + 轻打击（kick 每 2 拍、shaker 8 分音符弱）。
- 段落起伏：钩子段只有 pad；机制模拟段进钢琴；反直觉转折加 arp；结尾回落只剩 pad+单音钢琴。
- 响度 -14 LUFS，峰值 -1dB，无爆音。
- 换和弦对齐分镜章节切换点（见 synth_bgm.py 的 --sections）。
